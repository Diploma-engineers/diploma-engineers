📌 Book PDF Upload करने का पूरा तरीका

1

Admin Panel खोलें

सबसे पहले अपने Admin Panel में जाएँ। अगर Login नहीं है, तो पहले Login कर लें।

2

Book Section में जाएँ

Login करने के बाद Admin Panel में Book Section खोलें और Create New पर Click करें।

3

Book Title डालें

Book Title में Subject का नाम लिखें। उदाहरण: अगर FEE की PDF upload करनी है, तो Title में FEE लिखें।

4

PDF या Video File चुनें

Book के लिए Book PDF और Notes के लिए Notes PDF select करें। जरूरत के अनुसार Video File भी upload की जा सकती है।

5

PDF Link का इस्तेमाल करें

अगर आपके पास PDF का direct link है, तो उसे इस्तेमाल करना बेहतर रहेगा। इससे बड़ी PDF file को सीधे upload करने की जरूरत नहीं पड़ती।

6

Cover Page Upload करें

अब Book का Cover Page upload करें। Cover Page नहीं है तो available option से नया Cover Page बनाया जा सकता है।

7

File Size Check करें

Cover Page और PDF File का size upload limit के अंदर रखें। आपकी current setup में 10 MB limit रखी गई है।

8

बड़ी PDF के लिए Google Drive Link

अगर PDF 10 MB से ज्यादा है, तो उसे Google Drive पर upload करके shareable/direct-access link को Book details में डालें।

9

Create पर Click करें

सारी details, Cover Page और File/Link check करने के बाद Create पर Click करें। इसके बाद Book App में upload हो जाएगी।

⚠️ Important: Google Drive में link डालते समय यह सुनिश्चित करें कि file की sharing/access setting ऐसी हो कि App उसे पढ़ सके। साथ ही आपकी Admin Panel की actual upload/link limit को प्राथमिकता दें।

✅ Quick Checklist

  • Admin Panel में Login किया
  • Book → Create New खोला
  • Book Title / Subject Name डाला
  • Book PDF या Notes PDF / Video File select की
  • Cover Page upload किया
  • File size और link access check किया
  • Create पर Click किया
